# Interactive 3D Website

A scroll-driven 3D web experience built with React, Three.js and React Three Fiber. The page combines a real-time 3D scene with motion-led sections to explore how depth, typography and interaction can work together on the web.

## Live demo

[interactive-3d-website-pi.vercel.app](https://interactive-3d-website-pi.vercel.app/)

## What’s inside

- A 3D scene rendered with Three.js and React Three Fiber
- Scroll-linked transitions and animation timelines with GSAP ScrollTrigger
- Smooth scrolling with Lenis
- A multi-section landing page designed around the 3D experience
- Responsive viewport and scroll handling

## Tech stack

- React
- Three.js
- React Three Fiber and Drei
- GSAP and ScrollTrigger
- Lenis
- Vite

## Run locally

Requires Node.js and npm.

```bash
git clone https://github.com/Lemanzakarya/interactive-3d-website.git
cd interactive-3d-website
npm install
npm run dev
```

Create a production build:

```bash
npm run build
```
